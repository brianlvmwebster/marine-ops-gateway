Outlook account switching added 2026-11-09. Connected dashboard shows Change Outlook account. It opens a confirmation before starting the existing Floot-managed Microsoft OAuth popup. Callback accepts a different email and calls switchCalendarAccount in a database transaction. Same-email reconnection (case-insensitive) preserves event links. Different email resets event IDs, ETags, synced versions, subscription state, webhook base and secret while preserving all job data and old Outlook events. Next sync creates links in new mailbox. Live notifications must be re-enabled afterward. Sync and subscription renewal acquire a connection lease and use the returned connection row; switching locks the row and refuses an active lease. This avoids old-mailbox writes updating new-mailbox links.
