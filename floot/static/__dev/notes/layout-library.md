# Shared layout library
The /layouts editor starts blank on each visit. Named plans are stored in saved_layouts and shared with approved Microsoft gateway members. Save updates the active plan, Save as creates a separate plan, and Saved layouts provides load, rename and delete. Revision matching prevents stale writes/deletes. Browser drafts are recoverable explicitly and JSON export/import remains available.
Database migration: create saved_layouts(id uuid primary key, name text not null check(length(trim(name)) between 1 and 100), document jsonb not null check(jsonb_typeof(document)='object'), revision integer not null default 1, updated_by text not null, created_at timestamptz not null default now(), updated_at timestamptz not null default now()); create index saved_layouts_updated on saved_layouts(updated_at desc).
