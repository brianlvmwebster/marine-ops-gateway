# Live search

Customer search shows a compact dropdown after 200 ms without typing, with up to eight matching names and addresses. Typing leaves the main list unchanged; pressing Enter applies the query to that list and resets its pagination. Clearing the field and pressing Enter restores the full list. Clicking a quick result opens the full customer details through a shareable company/customer URL. The dropdown supports Tab/arrow navigation and Escape, and closes when focus leaves it.

Unit directories, Parts Inventory, job customer/unit/parts lookups, unit-owner lookup, and Dock Builder customer/saved-quote searches update automatically after 200 ms without typing. Enter and existing search buttons remain optional there. Directory queries reset pagination; clearing a directory query restores its unfiltered list. Lookups remain editable while fetching, cancel superseded requests, and never select or save a record automatically.
